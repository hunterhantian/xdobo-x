# xdobo X 官方账号引流系统设计方案

**版本**：基于历次讨论整理  
**核心目标**：在内部与其他渠道（官网、Facebook、TikTok、平台）竞争的情况下，把 X 做成可控的新客引流渠道，最终把线索交给本部门掌控的客服团队。

---

## 一、部门竞争环境下的运营原则

### 1.1 核心利益排序
1. **线索归属清晰**（来源必须标记为「X」）
2. **客户关系控制在本部门**（从第一句话开始就属于 X 团队）
3. **减少对其他渠道的依赖**（外部链接能不挂就不挂）
4. **可量化贡献**（DM 数、有效线索数、成交数可汇报）

### 1.2 关键策略
- **优先「留在 X 内」**：主路径用 DM 关键词触发，而不是跳转官网。
- **X 专属权益**：给 X 来源用户专属折扣码、优先发货、批发专属报价，制造「在 X 找你们最划算」的感知。
- **内容搬运 + X 化改造**：全网素材都可以用，但必须加上 X 专属 CTA（DM 关键词）。
- **归因与内部博弈**：所有 X 来源询盘，客服第一句话就标记「X客户」；争取 X 专属客服席位或优先处理权。

### 1.3 推荐执行要点
| 项目 | 建议 |
|------|------|
| Bio | 「官方X · 24小时内回复 · DM获取报价/批发」 |
| 置顶帖 | 高能产品视频 + 明确 DM 引导 |
| 内容比例 | 60% 场景体验 / 25% 互动用户故事 / 15% 明确询盘引导 |
| 链接策略 | 主帖尽量不挂外部链接；需要时放回复或 Bio（优先自己控制的轻量落地页/WhatsApp） |
| 差异化 | 公开承诺「X上询问24小时内回复」；发工厂实力、集装箱发货、B2B 数据时固定加 DM 引导 |

## 二、基于 Grok Bot 的整体引流系统设计

### 2.1 三层业务模型

```
吸引层（内容自动化） → 捕获层（Grok Bot 处理 DM） → 交接层（自动标记 + 通知客服）
```

### 2.2 第一层：吸引层（内容 Bot）

**Bot 名称建议**：内容生产Bot

**职责**：
- 从全网素材（TikTok、官网、工厂视频、用户晒单）中筛选并改写适合 X 的内容
- 统一加上 X 专属 CTA
- 输出草稿 + 建议发布时间

**固定 CTA 模板**：
> 想看完整测试/报价/批发目录，直接私信我关键词：BASS / WHOLESALE / PRICE

**自动化程度**：内容起草 70–80%，发布前人工确认一次。

### 2.3 第二层：捕获层（核心）

**Bot 名称建议**：线索处理Bot

**工作流**：
1. 用户通过关键词 CTA 主动发起 DM
2. Grok Bot 定时（每 15–30 分钟）检查新消息 / 消息请求（非实时触发，无法在收到私信的瞬间响应）
3. 识别关键词（BASS / WHOLESALE / PRICE / OEM）
4. 自动回复标准话术，收集：姓名 + WhatsApp/邮箱 + 需求类型（零售/批发/OEM）
5. 收集完整后，用固定格式总结并标记「X来源线索」

**推荐指令示例**：
> 你是 xdobo 官方客服助手。只处理用户主动发起的私信。  
> 当用户提到报价、批发、产品时，先礼貌回复并询问：姓名、WhatsApp或邮箱、具体需求（零售/批发/OEM）。  
> 收集完整信息后，用固定格式总结给我，并标记为「X来源线索」。  
> 不要主动私信陌生人，不要挂外部链接。

**进阶选项**：同时跑 X Lead Gen Ads（原生表单广告），线索直接在 X 内收集并导出，完全不需要人工首次回复。

### 2.4 第三层：交接层

- 回复时效：Bot 按定时巡检处理私信，对外承诺「24小时内回复」，不承诺实时回复
- Bot 每次巡检后，把新线索整理成固定格式邮件发给客服同事（字段：时间、姓名、WhatsApp/邮箱、需求类型、触发关键词、对话摘要、来源=X）
- 可选同步写入 WPS 表格，方便同事查阅与统计；主交接通道是邮件，不以微信群通知为准
- 线索邮件发出（并可选写入 WPS），即视为交接完成
- 客服团队只接收已标记为「X来源」的线索
- 定期统计 DM 数量、有效线索数、转化情况，用于向上汇报

## 三、关键词体系与账号设置

| 关键词 | 用途 |
|--------|------|
| BASS | 产品体验 / 零售询盘 |
| WHOLESALE | 批发合作 |
| PRICE | 报价 |
| OEM | 定制 / ODM |

**账号基础设置**：
- Bio 写清官方身份 + DM 关键词引导
- 置顶高能视频 + 明确 CTA
- 建议开通 X Premium（提升 DM 额度和送达率）

---

## 四、合规与风险控制

- 只回复用户先发起的消息，不做冷启动群发
- 优先使用 Grok Bot 官方 X DM 功能（相对第三方工具更合规）
- 高价值线索保留人工接管
- 避免纯产品堆砌，否则用户不会主动 DM

---

## 五、推荐启动顺序

1. 先建「线索处理Bot」，连接 X，跑 1–2 周测试关键词回复效果
2. 再建「内容Bot」，开始稳定输出带 CTA 的内容
3. 跑通后叠加 X Lead Gen Ads 做付费放大
4. 建立线索邮件自动转发（可选同步 WPS 表格），形成闭环

---

## 六、成本与工具参考

| 项目 | 说明 |
|------|------|
| Grok Bot | 核心自动化引擎（内容 + DM 处理） |
| X Premium | 建议开通（约 $8/月，提升 DM 额度与送达） |

| X Lead Gen Ads | 可选，原生表单直接收集线索，零人工首次回复 |
| 第三方辅助（可选） | OpenTweet / Xlift / DMpilot 等，用于半自动回复辅助 |

---

**总结**：  
整套系统的核心是用 Grok Bot 把「内容生产」和「DM 回复 + 线索记录」这两件最耗人力的事自动化，同时通过关键词 CTA 和来源标记，确保客户关系与业务贡献牢牢留在 X 部门和本部门手里。
